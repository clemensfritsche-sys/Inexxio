# Marken-Logos (Fahrmischer)

Ein Logo je Marke aus `config/site.mjs` (`marks.mixers`) als SVG, Dateiname = Marke klein
geschrieben: `liebherr.svg`, `putzmeister.svg`, `cifa.svg`, `stetter.svg`, `intermix.svg`,
`belmix.svg`, `peter.svg`. Quelle: Pressebereich der Hersteller (Originaldatei, nicht nachgezeichnet).

Liegt eine Datei hier, zeigt das Marken-Band (`components/fahrzeug/BrandBand.astro`) das Logo
in schwachem Grau, beim Zeigen in Farbe; fehlt sie, steht der Name. Nichts sonst zu tun.
